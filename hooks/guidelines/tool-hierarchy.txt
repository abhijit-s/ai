Follow this tool order and stop at the first tool that fits:

1. fff MCP (`mcp__fff__grep`, `mcp__fff__find_files`, `mcp__fff__multi_grep`) — FIRST CHOICE for all file search, glob, and grep inside the git-indexed project.
   IMPORTANT: fff MCP tools are deferred — their schemas are not loaded by default. You MUST call ToolSearch with `query: "select:mcp__fff__grep,mcp__fff__find_files,mcp__fff__multi_grep"` before calling any `mcp__fff__*` tool, or you will get an InputValidationError.
   Once loaded, USE THEM. Do not load fff MCP and then fall back to grep/find anyway — that defeats the purpose.
2. ast-grep — Syntax-aware structural code search when fff MCP is insufficient.
3. rg (ripgrep) — Full-text search when fff MCP / ast-grep don't fit. Use full language names: `--type ruby` (not `--type rb`), `--type typescript`, etc.
4. fd — File discovery by name/pattern. NEVER use `find` instead of `fd`.
5. grep / find — LAST RESORT ONLY when the above tools have each genuinely failed or are unavailable.

Never skip to a lower tier when a higher one fits the task. Loading a higher-tier tool and then ignoring it counts as skipping.
